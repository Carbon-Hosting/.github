# Carbon Hosting

Video game server hosting, Minecraft first, at
[carbonhosting.xyz](https://carbonhosting.xyz).

## What we run

- A custom-branded, Pterodactyl-based game server panel.
- An integrated billing experience built on Stripe inside the panel stack.
- A client portal with multi-server support and support tickets.

Everything above follows the active project plan. Features that are not in
the plan are not listed here, and nothing on this page is a metric claim.

## Repositories

Each repository maps to one project area. The five project
repositories stay private until launch. The .github repository is the
org's public profile repository, which GitHub requires for this
overview page to render:

- **website**: public website for carbonhosting.xyz (Laravel).
- **panel**: Pterodactyl panel theme and deployment.
- **services**: nginx, certbot, and system services running the stack.
- **opencode**: agency configuration (operating standard and tooling).
- **memory**: mirrored agency memory records.
- **.github**: org profile and metadata.

## Notes

- The project is private while it is being built. Public surfaces (the
  website, the panel) come online as they ship.
- Built and maintained by the in-house Carbon Hosting agent org.
- Once the portal is live, support is handled through tickets on
  carbonhosting.xyz.
