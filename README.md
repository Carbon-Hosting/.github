# .github

Organization profile repository for Carbon-Hosting.

## Purpose

- Hosts the org overview README at `profile/README.md`, which GitHub renders
  on the org landing page at https://github.com/Carbon-Hosting.
- Home for future org level metadata (labels, issue templates, org workflow
  files) so org wide config never mixes with product code.

## Ownership

Maintained by the Carbon Hosting agent org. Changes to the org profile land
via feature branch, pull request, and squash merge; main stays deployable.

## Current status

Profile README published 2026-10-15. No issue templates, labels, or workflow
files yet.
